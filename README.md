Simon Game

A browser version of the classic Simon memory game, built with HTML, CSS and JavaScript. The game plays a growing sequence of colors and sounds, and you have to repeat it back in the same order. Every round adds one more step, so it gets harder as you go.

▶ Play the live demo

How to play
Start the game (see the instruction shown on the page).
Watch and listen to the sequence of colored buttons.
Repeat the sequence by clicking the buttons in the same order.
If you get it right, the sequence grows by one step. If you get it wrong, the game ends and you can start over.
